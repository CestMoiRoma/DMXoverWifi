Wired Ethernet beta

A W5500 module on SPI, as an alternative to WiFi. Addressing lives on the Network page. Takes effect on the next reboot.

Save-guard

Remembers the look and puts it back after a reboot or a power cut. Only channels holding a value are stored, and the board waits for the rig to be still for ten seconds before writing, so a dragged fader does not spend the flash's erase cycles.

Language

Remembered in this browser, not on the board, so two people looking at the same rig need not agree on a language.

Firmware

Running version …. An update rewrites the program only: fixtures, scenes, groups, labels and network settings are on a separate partition and are left exactly as they are. DMX output stops while the file transfers and the board reboots after it, so do this with the rig dark rather than mid-show.

Reboot

Pin changes, hostname changes and the WiFi switch only take effect on restart. DMX output stops for a couple of seconds.

DMX output

On the ESP8266 the DMX output is wired to Serial1 on GPIO2 by the backend and cannot be moved, so there is nothing to configure here.

Legacy .env export

The same config as a hand-editable .env. Drop it next to platformio.ini to pre-fill a board at flash time.
